Thesis Information

  • Title: Hybrid Representation for Neural and Parametric 3D Animal Model
  • Student: Paulína Jančárová
  • Supervisor: Mgr. Martin Halaj
  • Consultant: doc. RNDr. Martin Madaras, PhD.
  • Description: This thesis investigates hybrid approaches to the representation and rendering of 3D models by combining traditional parametric polygonal meshes with neural representations such as Neural Radiance Fields (NeRFs) or 3D Gaussian Splatting (3DGS). The goal is to design a hybrid representation of a 3D animal model, where the body is modeled using a parametric mesh and the fur is represented using one of the aforementioned neural representations.

Results

The following results were obtained using these steps:

  1. Imported a SMAL model into Blender
  2. Added fur to the SMAL model using Blender’s built-in Curves Fur system
  3. Set up camera keyframes to capture the model from multiple angles
  4. Rendered the keyframed camera sequence
  5. Used a Python script to extract camera positions from Blender
  6. Created a fur-only mesh with a significantly reduced fur count, then generated a point cloud from it using a Python script
  7. Trained Nerfstudio's Splatfacto model using rendered images of the model, camera positions, and the fur point cloud as input data
  8. Exported the trained 3DGS scene as a PLY file
